**MyGemini Zero** — это не просто еще один Telegram-бот. Это ваш личный, безопасный и по-настоящему умный шлюз к возможностям Google Gemini, построенный на принципах **полной приватности и долгосрочной памяти**.

В отличие от стандартных чатов, которые "забывают" все после каждого разговора, MyGemini Zero превращает нейросеть из гения с амнезией в вашего персонального ассистента, который **помнит, учится и адаптируется** под вас. И все это — с криптографической гарантией того, что никто, даже администраторы сервиса, не сможет прочитать ваши данные.

## 🌟 У меня есть ChatGPT/Gemini. Зачем мне платить за вашего бота?

Это главный вопрос, и у нас есть четыре ответа:

#### 1. **Память: Ваш личный "второй мозг"**
*   **Проблема:** Стандартные чат-боты не помнят ваших прошлых разговоров. Вы вынуждены повторять контекст, снова и снова объяснять свои цели и проекты.
*   **Наше решение:** MyGemini Zero интегрирован с **персональной векторной базой данных**. Каждый ваш диалог, загруженный документ или важная мысль превращается в "воспоминание". Когда вы задаете новый вопрос, бот автоматически находит релевантный контекст из прошлого и добавляет его к запросу.
    *   **Результат:** Вы можете спросить "Какие были ключевые риски в проекте, который мы обсуждали на прошлой неделе?" или "Напомни основные идеи из той статьи про маркетинг", и бот поймет, о чем речь. Он становится вашим личным, всегда доступным "вторым мозгом".

#### 2. **Приватность: Архитектура "Нулевого Знания" (Zero-Knowledge)**
*   **Проблема:** Используя сторонние боты, вы доверяете свои данные не только Google/OpenAI, но и разработчику бота-посредника. Вы не знаете, как он хранит ваши диалоги и кто имеет к ним доступ.
*   **Наше решение:** Мы используем архитектуру, при которой все ваши данные (история, файлы, API-ключ) шифруются **мастер-паролем**, который знаете **только вы**.
    *   **Результат:** Мы, как создатели сервиса, **криптографически не можем** прочитать ваши данные. У нас просто нет ключа от вашего "цифрового сейфа". Если вы забудете пароль, ваши данные будут утеряны навсегда, потому что восстановить их не сможет никто. Это максимальная приватность в обмен на вашу личную ответственность.

#### 3. **Персонализация: Бот, который знает вас**
*   **Проблема:** Стандартные модели дают общие ответы, не учитывая вашу профессию, стиль общения и цели.
*   **Наше решение:** При первом запуске бот предлагает вам заполнить краткую анкету-профиль. Эта информация становится фундаментом для его работы. В сочетании с долгосрочной памятью это позволяет боту давать ответы, адаптированные именно под вас.
    *   **Результат:** Ответ для разработчика будет содержать код и технические детали, а ответ для менеджера — структуру, сроки и ключевые метрики. Бот говорит с вами на одном языке.

#### 4. **Удобство: Готовый сервис "под ключ"**
*   **Проблема:** Самостоятельная настройка и поддержка такого сложного инструмента требует времени, технических знаний и постоянного обслуживания.
*   **Наше решение:** Мы берем все это на себя. Вам не нужно разбираться в серверах, базах данных и обновлениях. Вы получаете готовый, стабильный и постоянно развивающийся сервис.
    *   **Результат:** Вы просто пользуетесь всеми преимуществами, экономя десятки часов на технической рутине. Вы платите не за код (он открыт), а за **удобство, стабильность и безопасность**.

## 🔐 Как работает безопасность (Zero-Knowledge)?

Представьте, что ваши данные — это сокровище в сейфе.

1.  **Вы создаете уникальный ключ:** При регистрации вы придумываете **мастер-пароль**. Этот пароль — единственный существующий физический ключ от вашего сейфа.
2.  **Мы не храним ваш ключ:** Мы не сохраняем ваш пароль. Мы сохраняем только его зашифрованный "отпечаток" (хеш), по которому невозможно восстановить сам пароль.
3.  **Ключ шифрования создается "на лету":** Каждый раз, когда вы вводите пароль для разблокировки сессии, из него и вашей персональной "соли" генерируется временный ключ шифрования. Он существует только в оперативной памяти и исчезает после окончания сессии.
4.  **Все данные зашифрованы:** Этим временным ключом шифруется абсолютно всё:
    *   Ваш Google API-ключ.
    *   История всех ваших диалогов.
    *   Данные вашего профиля.
    *   Ваша долговременная память (векторная база).

> **Прозрачность — наш принцип.** Мы защищаем ваши данные от нас (посредника). Но финальный запрос (ваш промпт + контекст из памяти) отправляется в Google Gemini в расшифрованном виде. Наш сервис для тех, кто доверяет Google, но не хочет доверять сторонним разработчикам.

## ⚙️ Для энтузиастов: Настройка и запуск

Несмотря на то, что мы предлагаем готовый сервис, мы верим в открытость. Вы можете развернуть свой собственный экземпляр бота.

### Предварительные требования
*   **Python 3.10 или выше.**
*   **Git**

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone [https://github.com/kobaltgit/MyGemini_Zero]
    cd MyGemini_Zero
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # для Linux/macOS
    # или
    venv\Scripts\activate  # для Windows
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройте переменные окружения:**
    Создайте файл `.env` в корневой директории проекта и добавьте в него токен вашего Telegram-бота `BOT_TOKEN` и ваш Telegram ID `ADMIN_USER_ID`.

    ```env
    # Токен вашего Telegram-бота от @BotFather
    BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

    # Ваш Telegram User ID для админских прав
    ADMIN_USER_ID=123456789
    ```

### Запуск бота
```bash
python main.py
```
После запуска найдите бота в Telegram и отправьте команду `/start`. Он проведет вас через процесс создания мастер-пароля и настройки Google API-ключа.

---

## 💬 Основные команды
*   `/start` - Перезапустить бота или разблокировать сессию.
*   `/logout` - Заблокировать сессию (требует ввода пароля при следующем действии).
*   `/profile` - Просмотреть и изменить свой профиль.
*   `/dialogs` - Открыть меню управления диалогами.
*   `/settings` - Открыть меню настроек (выбор персоны, модели, языка).
*   `/usage` - Показать статистику расходов токенов Google API.
*   `/history` - Посмотреть историю сообщений в текущем диалоге.
*   `/reset` - Сбросить *краткосрочный* контекст текущего диалога (не влияет на долговременную память).
