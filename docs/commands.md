# Справочник команд

Здесь перечислены все доступные команды и их описание.


=== "Основные команды"

    | Команда | Описание |
    | :--- | :--- |
    | `/start` | **Перезапустить бота или разблокировать сессию.** Если ваша сессия заблокирована по таймауту или после команды `/logout`, `/start` инициирует запрос мастер-пароля. |
    | `/logout` | **Заблокировать сессию.** Немедленно завершает вашу текущую сессию. Все зашифрованные данные становятся недоступными до следующего ввода мастер-пароля. |
    | `/help` | **Показать краткую справку.** Выводит в Telegram список основных команд. |
    | `/help_guide`| **Открыть полное руководство.** Отправляет ссылку на этот сайт. |

=== "Управление памятью и диалогами"

    | Команда | Описание |
    | :--- | :--- |
    | `/dialogs` | **Открыть меню управления диалогами.** Позволяет создавать новые диалоги, переключаться между существующими, переименовывать их и удалять. |
    | `/memorize`| **Запомнить содержимое файла.** Бот попросит вас отправить текстовый файл (`.txt`, `.md`), содержимое которого будет добавлено в долговременную память **текущего диалога**. |
    | `/reset` | **Сбросить краткосрочный контекст.** Очищает "оперативную память" текущего диалога, не затрагивая при этом долговременную память (содержимое файлов и прошлых бесед). Полезно, когда вы хотите начать новую тему в рамках того же диалога. |
    | `/history` | **Посмотреть историю сообщений.** Открывает календарь для выбора даты, за которую вы хотите просмотреть историю сообщений в текущем диалоге. |
    | `/archive` | **Архивировать старые сообщения.** Запускает процесс сжатия старых сообщений в текущем диалоге, заменяя их краткими сводками для экономии места и ускорения поиска. |

=== "Настройки и Персонализация"

    | Команда | Описание |
    | :--- | :--- |
    | `/profile` | **Просмотреть и изменить свой профиль.** Показывает данные из вашей анкеты и позволяет отредактировать любой из ответов, чтобы изменить то, как ИИ вас воспринимает. |
    | `/settings`| **Открыть меню настроек.** Позволяет изменить модель Gemini, выбрать "персону" (стиль ответов), язык интерфейса и управлять данными. |
    | `/set_api_key`| **Установить или обновить API-ключ Google.** Запускает процесс ввода вашего Google AI API ключа. |
    | `/usage` | **Показать статистику расходов токенов.** Отображает информацию о количестве использованных токенов Google API за сегодня и за текущий месяц, а также примерную стоимость. |
